The Form No. 137 FVU setup comprises of two files namely

Form No. 137 FVU.bat: This is a setup program for installation of FVU.
Form No. 137_FVU_STANDALONE.jar: This is the FVU program file.


These files are in an executable zip file (Form-No.173-FVU.exe). These files are required for installing the Form No. 137 FVU.
